# Cafetería Vegana de Barrio

Proyecto final del curso de Desarrollo Web de Coderhouse.

## Descripción

Sitio web responsive de una cafetería vegana de barrio. Incluye información sobre el menú, la historia de la cafetería, cursos de cocina vegana y un formulario de contacto.

## Tecnologías utilizadas

- HTML5
- CSS3 y SCSS (Sass)
- Bootstrap 5
- Animate.css

## Páginas

- Inicio
- Menú
- Sobre Nosotros
- Cursos
- Contacto
